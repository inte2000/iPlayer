具体要求：

1、通过 cmake/FindLibcdio.cmake 引入 libcdio 库的支持。
2、Open 函数根据 name 的格式判断是光盘设备还是映像文件，如果名字格式是 \\device\X: 的形式，其中 X 是26 个英文字母，则是光盘设备。
3、libcdio 如果打开成功，则认为是 AudioCD，其他格式的光盘暂时先返回 false。

5、利用 libcdio 实现 SectorSource 接口，暂时只支持 SectorSourceType::AudioCD 即可
6、DataStream的接口可用利用 SectorSource 接口实现，保证二者的换算。为了简化换算，CCDSectorsStream 内可存储一个当前扇区逻辑编号，表示当前读取数据将从这个扇区开始。 DataStream::Read(void* pBuf, uint32_t size, uint32_t timeout = 0) 从这个扇区开始读，根据 size 圆整到整数个扇区，返回实际读取的数据字节数（读取的完整扇区数 x 扇区大小）。DataStream::Seek 的位置必须是扇区大小的整数倍位置。
